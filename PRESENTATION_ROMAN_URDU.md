## SLIDE 8 — SECURITY FEATURES

### Website Kitni Secure Hai?

**Firebase Authentication:**
- Industry standard security
- JWT tokens automatically manage hote hain
- Passwords Firebase encrypt karta hai

**Role-Based Access Control (RBAC):**
```
Admin  → Sab kuch access kar sakta hai
Owner  → Sirf apna restaurant manage kar sakta hai
Customer → Sirf browse aur order kar sakta hai
```

**Firestore Security Rules:**
- Users sirf apna data edit kar sakte hain
- Restaurant owners sirf apna restaurant update kar sakte hain
- Public data (restaurants, menus) sab dekh sakte hain
- Orders sirf logged in users place kar sakte hain
