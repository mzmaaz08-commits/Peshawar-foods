# Evaluation Guide - Website Start Karne Ke Steps

## 🚀 Evaluation Mein Website Start Karne Ke 3 Simple Steps

### **Step 1: VS Code Mein Project Open Karein**
1. VS Code open karein
2. File → Open Folder
3. Is folder select karein:
   ```
   c:\Users\Administrator\OneDrive\Main projects\peshawar-restaurants
   ```
4. Open button par click karein

---

### **Step 2: Terminal Open Kar Command Run Karein**
1. VS Code mein terminal open karein:
   - `Ctrl + ~` (tilde key) ya
   - View → Terminal
2. Terminal mein ye command likhein aur Enter dabayein:
   ```bash
   npm run dev
   ```
3. Wait karein jab tak ye message na aaye:
   ```
   Local: http://localhost:5174
   ```

---

### **Step 3: Browser Mein Website Open Karein**
1. Chrome ya koi browser open karein
2. Address bar mein ye likhein:
   ```
   http://localhost:5174
   ```
3. Enter dabayein
4. Website open ho jayegi!

---

## ✅ Done! Website Chal Rahi Hai

Ab aap demo de sakte hain. Terminal ko band mat karein jab tak evaluation chal rahi hai.

---

## 🛑 Server Stop Karne Ke Liye (Evaluation Ke Baad)
Terminal mein `Ctrl + C` dabayein.

---

## ⚠️ Important Notes:

- **Terminal ko band mat karein** jab tak demo chal raha hai
- **Agar pehli baar kar rahe hain** toh pehle `npm install` run karein
- **Agar error aaye** toh mujhe bataiye
- **Internet connection on** hona chahiye (Firebase ke liye)
